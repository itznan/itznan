## Some things I've built

**nanaccel**  
A lightweight, high-performance GPU-accelerated video decoder, encoder, and shader processing engine built in Rust. Leverages pure Direct3D 11 / DXGI Desktop Duplication and NVIDIA NVDEC/NVENC hardware pipelines for zero-copy processing, dynamic runtime HLSL pixel shader injection, 60 FPS real-time desktop recording, and native audio DSP.  
Explore on [GitHub](https://github.com/itznan/nanaccel)

**dspd**  
A fast, safe, single-binary disk benchmarking and storage telemetry suite for Windows, written in Rust. Features dual asynchronous storage engines utilizing native Win32 I/O Completion Ports (IOCP) and Windows 11 `IoRing` kernel ring buffers, unbuffered page-aligned direct I/O, NVMe SMART thermal health polling, and pseudo-SLC cache cliff analysis.  
Explore on [GitHub](https://github.com/itznan/dspd)

**stash**  
A minimalist, 100% offline personal finance, dual-wallet, and peer-to-peer loan tracker for Android built with Jetpack Compose and Material 3 (Monet dynamic theming). Operates with zero internet permissions for total privacy, featuring dual-wallet tracking (Bank/UPI vs. Cash), P2P loan management with direct communication shortcuts, 120Hz LTPO display optimizations, and biometric security.  
Explore on [GitHub](https://github.com/itznan/stash)

**obs-mcp**  
An enhanced Model Context Protocol (MCP) server for OBS Studio with 100% OBS WebSocket v5 protocol parity. Implements atomic batch macros (`RequestBatch` OpCode 8/9), real-time 100-event circular ring buffering, native multimodal ImageContent vision inspection, production safety guardrails, dynamic tool filtering, and consolidated compound tools in TypeScript and Python.  
Explore on [GitHub](https://github.com/itznan/obs-mcp)

**naantree**  
A modular multi-agent coordination protocol and CLI for autonomous AI coding agents collaborating in the same repository and branch. Implements atomic agent lifecycle management, collision-free recursive path claims, serialized commits with atomic git locks, peer review gates, structured messaging, and zero-token-waste event waiting.  
Explore on [GitHub](https://github.com/itznan/naantree)

**comixapi**  
A high-performance FastAPI REST API & scraper service for manga, manhwa & webtoons. Features a decoupled asynchronous Playwright session daemon, persistent browser state management to seamlessly resolve Cloudflare challenges, dynamic TLS fingerprint impersonation via `curl_cffi`, CORS/CORP media proxies, and automated format compilers (`.cbz` with `ComicInfo.xml`, `.epub`, `.pdf`).  
Explore on [GitHub](https://github.com/itznan/comixapi)

**fanrgbmpgb550**  
A zero-overhead, native Rust CLI lighting and motherboard controller for MSI MPG B550 Gaming Plus motherboards and Gigabyte RTX 3060 Ti GPUs. Bypasses bloated vendor software through direct USB HID (`0x52`) feature reports and NVAPI I2C probes, strictly writes to volatile RAM to prevent EEPROM flash wear, and features a real-time WASAPI sub-bass audio visualizer.  
Explore on [GitHub](https://github.com/itznan/fanrgbmpgb550)

**pankha**  
A unified hardware fan control and telemetry application designed specifically for 64-bit systems. Consolidates disparate cooling channels (motherboard Super I/O, CPU AIO pumps, and GPU fans) into a centralized, low-latency control interface with automated duty-cycle calibration, dynamic custom curves, and failsafe thermal cutoffs.  
Explore on [GitHub](https://github.com/itznan/pankha)

**wincallnotifier**  
A lightweight, 100% offline desktop and system tray application written entirely in Rust. Monitors incoming Android 15 phone call states via USB and ADB shell transports without requiring any APK installed on the phone, delivering native toast notifications with zero cloud reliance.  
Explore on [GitHub](https://github.com/itznan/wincallnotifier)

**locsim**  
A universal, cross-platform location simulator written in 100% safe Rust (published on [crates.io](https://crates.io/crates/locsim)). Seamlessly simulates device coordinates, altitude, accuracy, speed, and heading across Linux, Windows, Android emulators, iOS simulators, and headless browsers with a single unified CLI.  
Explore on [GitHub](https://github.com/itznan/locsim)
